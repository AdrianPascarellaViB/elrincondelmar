Notes de Disseny i Decisions Tècniques

Tècniques CSS utilitzades

  • Variables CSS (:root) per colors i tipografies
  • CSS Grid per als layouts de totes les pàgines
  • Menú hamburguesa: CSS-only (checkbox + sibling selector)
  • Banner cookies: CSS-only (~ selector general sibling)
  • Disseny responsiu amb media queries (1024px i 768px)
  • Transicions suaus per a interaccions
  • Iframe responsiu per al vídeo (padding-bottom 56.25%)

Funcionalitats HTML semàntiques

  • Tags semàntiques: <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>, <figure>
  • Schema.org JSON-LD (metadades estructurades, index.html)
  • Open Graph per a xarxes socials
  • Formulari RGPD amb caselles de consentiment
  • Taules amb colspan i rowspan
  • Llistes <ol> / <ul> anidades
  • Atributs ARIA per accessibilitat

Paleta de colors

--primary: #1a5276 (blau mediterrani)
--primary-dark: #154360
--secondary: #d4ac0d (or mediterrani)
--bg-light: #faf9f7
